# Incident & Postmortem Context

- **Linear**: look for incident labels. Names vary by team. Common examples: `incident`, `sev-*`, `postmortem-action-item`, `reliability`
- **Slack**: search incident channels around the dates the target code was added. Names vary by team. Common examples: `#sev-*`, `#incident-*`
- **Git**: commits with messages like "fix for incident", "add defensive check", "revert" followed by "re-apply with..." are strong signals
